01 Orientación

Tu ruta de trabajo

El proceso recomendado: crear un curso, editar sus semanas en Markdown y comprobar el resultado en el navegador.

1InstalarNode.js, npm y un editor.
2Crear cursoUn comando npm crea el proyecto.
3ConfigurarNombre, año y semanas activas.
4Crear semanasHasta ocho, con su propio Markdown.
5EditarElige layouts en la galería y copia su código.
6Añadir actividadesMicroactividades, quizzes y simuladores.
7PresentarVista del presentador, pizarra y PDF.
8PublicarSitio estático en GitHub Pages.
¿Quieres ver todo funcionando primero? Abre la demostración completa «TEMÁTICA DE PRUEBA»: una sola presentación con los 13 layouts, código con scroll y paginado, video, fórmulas, Mermaid, Chart, actividades y notas. No es una semana del curso; es la referencia para copiar ejemplos.

Qué puedes construir

Una presentación general, hasta 8 semanas independientes, actividades HTML locales, ilustraciones, diagramas Mermaid, gráficos Chart.js, fórmulas y notas del docente.

Qué no hace por sí solo

Las preguntas del laboratorio son locales; Seminar, encuestas y preguntas multiusuario requieren un servidor adicional. No hay sincronización de notas ni calificaciones con Moodle de forma automática.

02 Instalar

Requisitos de instalación

Solo necesitas Node.js (incluye npm), un editor de texto y un navegador moderno. No hace falta saber React.

  • Node.js 20.19 o posterior (recomendado: la versión LTS de nodejs.org). npm se instala junto con Node.js.
  • Editor: Visual Studio Code u otro editor de texto plano.
  • Navegador: Chrome, Edge o Firefox actualizados.
  • Git (opcional): solo para publicar en GitHub Pages.
terminal
node -v    # debe mostrar v20.19.0 o superior
npm -v
En Windows, usa PowerShell o la terminal de VS Code. Si node no se reconoce, cierra y vuelve a abrir la terminal después de instalar Node.js.
03 Crear curso

Instalación y creación de un curso

Un único comando descarga el generador desde npm y crea una carpeta nueva con el curso completo. No crees cursos dentro de otro proyecto.

terminal
npm create openclass-uniminuto-revealjs@latest mi-curso
cd mi-curso
npm install
npm run dev

npm run dev abre el portal en http://localhost:8600/. Si ese puerto está ocupado, usa npm run dev -- --port 8610.

Con los fondos y logotipos institucionales

El paquete público trae un tema neutro con la misma composición. Si tu institución te entregó la carpeta de recursos institucionales, aplícala al crear el curso (o después, con --update-theme):

terminal
npm create openclass-uniminuto-revealjs@latest mi-curso -- --assets "RUTA\recursos-institucionales"

--assets solo copia imágenes (png, jpg, webp, svg) sobre public/, con los mismos nombres de archivo. No publiques esos recursos si no tienes autorización.

Otras opciones del generador

terminal
npx create-openclass-uniminuto-revealjs@latest --help          # ayuda
npx create-openclass-uniminuto-revealjs@latest mi-curso --iot  # nombre inicial «Introducción a Internet de las Cosas»
npx create-openclass-uniminuto-revealjs@latest mi-curso --install  # crea e instala dependencias
Dato práctico. Si el puerto 8600 está ocupado por tu curso de referencia, abre este nuevo en http://localhost:8610/. No necesitas iniciar varios procesos en la misma carpeta.

¿Qué encontrarás al abrir el portal?

Acceso a la presentación general, semanas activas, demostración de layouts, laboratorio y esta guía. Las semanas se muestran según generation.activeWeeks.

05 Personalización

Configura nombre, periodo y semanas

Edita openclass.config.json con un editor de texto como VS Code. No elimines claves existentes.

json
{
  "course": {
    "shortName": "micursoiot",
    "fullName": "Internet de las Cosas",
    "year": "2026",
    "description": "OpenClass de sensores, conectividad y aplicaciones"
  },
  "generation": {
    "weeksTotal": 8,
    "activeWeeks": [1, 2],
    "overwriteWeekContent": false
  }
}
Es un fragmento ilustrativo, no el archivo completo. Conserva los ocho objetos de weeks. El shortName se usa en las rutas y nombres de archivo; no lo cambies después de editar las semanas sin revisar sus nombres.

Modifica weeks[n].title, date, centralTheme y activity para ajustar la semana correspondiente.

06 Flujo académico

Activa y desarrolla las ocho semanas

Cada semana usa un Markdown propio y una ruta dentro del portal. Tus cambios académicos no se sobrescriben al regenerar los accesos.

terminal
npm run semana -- 2 --title "Sensores y actuadores" --date "2026-11-04" --theme "Medición y control"
npm run config
npm run dev -- --port 8610

El comando crea (si no existe) semanas/micursoiot_semana2.md y activa su enlace en el portal. Edita allí el contenido. Para una semana ya existente, evita --force-content: esa opción sí puede reemplazar el Markdown.

terminal
npm run semana -- 3 --title "Comunicación IoT" --date "2026-11-11"
# Abrir luego /semanas/micursoiot_semana3/

Modificar una semana existente

Abre semanas/<curso>_semanaN.md en VS Code, edita y guarda: con npm run dev abierto, el navegador se actualiza solo. Para cambiar el título o la fecha que muestra el portal, edita weeks[N-1] en openclass.config.json o vuelve a ejecutar npm run semana -- N --title "…" (el Markdown se conserva).

Modificar la presentación general

La presentación general del curso está en slides.md y se abre en /general/. Sigue las mismas reglas de Markdown y layouts que las semanas; preséntala en la primera sesión (objetivos, metodología, evaluación).

09 Contenido

Imágenes, videos y recursos institucionales

Los recursos locales se copian a public/ y se referencian desde Markdown. Así pueden publicarse junto al curso.

markdown
![Sensor de temperatura]({{BASE_URL}}imagenes/sensor-dht22.png)

<video controls preload="metadata" src="{{BASE_URL}}videos/demostracion.mp4">
  <track kind="captions" src="{{BASE_URL}}videos/demostracion.vtt" srclang="es" label="Español" default>
</video>

Imágenes paso a paso

  1. Copia el archivo a public/imagenes/ con un nombre sin espacios ni tildes (sensor-dht22.png).
  2. Usa un layout de imagen (oc-l-image-left, oc-l-image-right, oc-l-top-left u oc-l-top-right).
  3. Escribe la imagen antes de la lista, con un texto alternativo que describa lo que muestra.

Video

El video va solo en una diapositiva oc-l-multimedia y ocupa toda el área útil sin recortarse. Prefiere WebM o MP4 de menos de 50 MB y agrega subtítulos .vtt. Para YouTube usa la dirección de inserción:

html
<iframe title="Video de la clase" src="https://www.youtube-nocookie.com/embed/ID_DEL_VIDEO" allowfullscreen style="width:100%;height:100%;border:0"></iframe>

Incluir un iframe

Cualquier página que permita incrustarse puede mostrarse en oc-l-multimedia con un <iframe> de width:100%;height:100%. Para HTML propios en public/actividades/ añade sandbox="allow-scripts allow-forms". Si el sitio bloquea la incrustación verás un recuadro vacío: enlázalo con target="_blank".

Fondos y logotipos

No renombres los fondos: la portada usa slide-01-portada.png, las internas slide-05-template.png y el cierre slide-06-cierre.png; el bloque inferior derecho de la portada usa imagenes/acreditacion-openclass.png. El paquete público incluye versiones neutras con esos nombres; los recursos institucionales se aplican con --assets y solo deben publicarse con autorización.

10 Programación

Mostrar código: scroll o paginado

El layout oc-l-code resalta la sintaxis, conserva sangrías y añade el botón Copiar código. Tiene dos modos.

Scroll (predeterminado)

Todo el programa en una diapositiva, con desplazamiento vertical y horizontal, rueda del ratón y teclado. Mientras quede código por recorrer, las flechas desplazan el código; al llegar al borde, vuelven a cambiar de diapositiva (el control remoto sigue funcionando). El código nunca tapa el pie.

Paginado

Agrega data-oc-paginate="code": el bloque se divide en diapositivas de 16 líneas con el título «(continuación N)». Cámbialo con data-oc-lines="20" (de 4 a 22). Úsalo si vas a exportar a PDF.

markdown
## Programa completo (scroll)
<!-- .slide: class="oc-demo oc-l-code" data-background-image="{{BASE_URL}}fondos/slide-05-template.png" data-background-size="cover" -->

```python
# … tantas líneas como necesites …
```

---

## Programa por partes (paginado)
<!-- .slide: class="oc-demo oc-l-code" data-background-image="{{BASE_URL}}fondos/slide-05-template.png" data-background-size="cover" data-oc-paginate="code" -->

```javascript
// … programa extenso …
```

Resaltar por pasos: escribe los rangos después del lenguaje, por ejemplo ```python [1-3|5-8]; cada avance ilumina un grupo de líneas. La paginación de código no afecta al texto: para listas largas existe data-oc-paginate="auto".

Durante la clase: haz clic dentro del código para desplazarte con las flechas; pulsa Esc para soltar el foco. Ver ejemplos en la demostración.
11 Aprendizaje activo

Inserta actividades, simuladores y cuestionarios

El layout multimedia muestra actividades a gran tamaño. Los HTML locales se ejecutan dentro de un iframe aislado.

markdown
## Pregunta de repaso
<!-- .slide: class="oc-demo oc-l-multimedia" data-background-image="{{BASE_URL}}fondos/slide-05-template.png" data-background-size="cover" -->

<iframe title="Pregunta de repaso" src="{{BASE_URL}}actividades/quiz-iot.html"
        loading="lazy" sandbox="allow-scripts allow-forms"
        style="width:100%;height:100%;border:0"></iframe>

Microactividad de 5 a 10 minutos

En public/actividades/microactividad/ hay una actividad de clasificación con objetivo, instrucciones, validación, retroalimentación por respuesta, resultado observable, reinicio, cronómetro orientativo y acceso por teclado. Para cambiar el tema:

  1. Copia la carpeta con otro nombre, por ejemplo public/actividades/clasificar-sensores/.
  2. Edita solo datos.js: título, objetivo, minutos, categorías (2 a 5) y elementos con su explicación.
  3. Insértala con un iframe en oc-l-multimedia:
markdown
<iframe title="Clasificar sensores" src="{{BASE_URL}}actividades/clasificar-sensores/index.html" loading="lazy" sandbox="allow-scripts allow-forms" style="width:100%;height:100%;border:0"></iframe>

13 Inteligencia artificial

Construir una semana con IA

Cada curso incluye tres archivos en docs/IA/ para que ChatGPT, Claude, Codex u otra IA redacten una semana compatible con OpenClass, sin inventar clases ni recursos.

ArchivoPara qué sirve
INSTRUCCIONES-OPENCLASS.mdContrato técnico: arquitectura, sintaxis, 13 layouts, imágenes, código, Mermaid, Chart, fórmulas, iframes, actividades, restricciones y validación.
PLANTILLA-SEMANAL.mdFormulario para completar con curso, semana, tema, resultados, materiales, preguntas, actividades, evaluación y bibliografía (admite datos parciales).
PROMPT-CREAR-SEMANA.mdPrompt listo para copiar: secuencia pedagógica, diapositivas, microactividad, evaluación formativa, cierre, verificación y reporte de pendientes.
  1. Crea la semana: npm run semana -- 3 --title "Sensores".
  2. Completa docs/IA/PLANTILLA-SEMANAL.md con tu material (pega textos o adjunta documentos).
  3. Copia el prompt de PROMPT-CREAR-SEMANA.md en la IA y adjunta las instrucciones, la plantilla y el material.
  4. Guarda la respuesta en semanas/<curso>_semana3.md, revisa cada «PENDIENTE» y ejecuta npm run dev.
Revisión docente obligatoria: la IA no debe inventar bibliografía, enlaces ni videos; revisa los recursos marcados como pendientes y verifica cada enlace antes de la clase.

Vista del presentador

Uso de Chalkboard: comprueba borrado, guardado y recuperación de los trazos en el navegador antes de cada sesión. La persistencia puede depender del almacenamiento disponible y del contexto de navegación.
15 Compartir

Exportar a PDF

Reveal.js genera una página por diapositiva desde el propio navegador.

  1. Abre la presentación añadiendo ?print-pdf a la dirección, por ejemplo http://localhost:8600/semanas/micurso_semana1/?print-pdf.
  2. Espera a que cargue y pulsa Ctrl + P en Chrome o Edge.
  3. Destino: Guardar como PDF; márgenes: Ninguno; activa Gráficos de fondo.
Código y PDF: en modo scroll el PDF muestra solo la parte visible del programa; para entregar el código completo usa data-oc-paginate="code". Los fragmentos se imprimen como páginas separadas. Videos e iframes aparecen como imagen estática o en blanco.
16 Entrega

Validar, compilar y publicar

El sitio se compila como HTML/CSS/JS estático. Publica dist/, nunca el servidor de desarrollo Vite.

terminal
npm run test:estructura
npm run pages:check
npm run pages:build
npm run preview:pages

Publicar en GitHub Pages

  1. Crea un repositorio en GitHub y sube el curso (sin node_modules ni dist; el .gitignore incluido ya los excluye).
  2. En el repositorio: Settings → Pages → Source: GitHub Actions.
  3. Cada push a main ejecuta .github/workflows/deploy.yml: instala, compila con la base /<nombre-del-repositorio>/ y publica dist/.
  4. Abre https://<usuario>.github.io/<repositorio>/ y comprueba portal, semanas, imágenes y actividades.

La variable SITE_BASE determina el prefijo de ruta; los ejemplos de Markdown usan {{BASE_URL}} precisamente para respetarlo.

Recursos institucionales: si aplicaste --assets, publicar el curso también publica esos logotipos. Hazlo solo con autorización o usa un repositorio y despliegue privados.

El comando npm run publicar ejecuta Git (add, commit y push): no lo ejecutes hasta revisar el repositorio y confirmar que quieres publicar esos cambios.

17 Mantenimiento

Actualizar sin perder las clases redactadas

El generador rechaza carpetas no vacías. Para actualizar infraestructura, utiliza únicamente su opción segura sobre cursos OpenClass Reveal.js reconocidos.

powershell
# Desde la carpeta que contiene el curso:
npx create-openclass-uniminuto-revealjs@latest mi-curso-iot --update-theme
# (añade --assets "RUTA\recursos-institucionales" para reaplicar los recursos locales)

# Luego entra al curso y comprueba:
Set-Location '..\mi-curso-iot'
npm install
npm run test:estructura
npm run pages:build
Antes de actualizar: realiza tu propio respaldo o commit Git. --update-theme crea respaldos de la infraestructura sustituida, conserva los Markdown académicos y la configuración. No utilices --force ni ejecutes sobre proyectos Slidev.

Graphify es opcional para el mantenimiento técnico; no forma parte del flujo obligatorio para redactar semanas.

18 Solución de problemas

Errores comunes y cómo resolverlos

Estas son las incidencias que más se repiten al crear una OpenClass.

El puerto 8600 ya está ocupado

Ejecuta npm run dev -- --port 8610. Evita cerrar otro curso que tengas abierto.

El generador dice “Carpeta no vacía”

Usa un directorio nuevo. Para actualizar uno creado previamente con este generador, utiliza --update-theme; nunca sobreescribas indiscriminadamente.

La semana nueva no aparece en el portal

Ejecuta npm run semana -- N o modifica generation.activeWeeks y luego npm run config.

Un iframe externo está en blanco

La página puede prohibir ser incrustada. Prueba abrirla en otra pestaña o utiliza una actividad HTML local dentro de public/actividades.

Las fórmulas o plugins no cargan sin internet

La configuración Math actual puede usar CDN. Valida conectividad y evita prometer uso desconectado hasta comprobar las dependencias.

El PowerShell bloquea scripts .ps1

Para crear cursos usa node bin/create-openclass-uniminuto-revealjs.mjs; no requiere cambiar la política global de ejecución.

Aparecen advertencias npm audit o chunks grandes

Un build PASS no elimina advertencias de seguridad. Revisa npm audit por dependencia y evita npm audit fix --force sin evaluar cambios incompatibles.

19 Extensiones futuras

Encuestas, preguntas y participación en vivo

La estructura incluye Seminar, Poll y Questions, pero permanecen desactivados para no simular interacción multiusuario inexistente.

Para activarlos se necesita un servidor de tiempo real compatible, conexiones seguras HTTPS/WSS, salas, autenticación o tokens, moderación y protección contra abuso. Zoom puede funcionar como canal de videollamada mientras OpenClass se abre como web interactiva, pero una integración embebida en Zoom requiere un proyecto y validación propios.

Estado actual: disponibles las actividades locales y plugins docentes; servidor de participación y Zoom pendientes.
