# Instrucciones para agentes de código (Claude Code, Codex, Gemini CLI, Copilot…)

Este proyecto pertenece a WillEdTech y debe respetar su sistema de marca.

1. Antes de crear o modificar cualquier interfaz, logo, favicon, presentación o imagen, lee `brand/BRAND.md`.
2. Usa los logos de `brand/logo/` y `brand/products/<app>/` tal cual, sin redibujarlos.
3. Para estilos, usa los tokens de `brand/tokens/tailwind.config.js` como preset de Tailwind, o `brand/tokens/willedtech.css` si el proyecto no usa Tailwind. No uses colores ni fuentes fuera de esa guía.
4. Si hace falta una sub-marca nueva, sigue la "Receta para un producto nuevo" de BRAND.md.
5. Si algo de la guía no se puede cumplir, dilo explícitamente en tu respuesta en lugar de improvisar.
